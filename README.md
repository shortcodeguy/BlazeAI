# BlazeAI v5

**Created by ShortCodeGuy Studio**

A genuine local AI chatbot in Python designed for real-time CPU inference on an **Intel Core i3-1215U** with **8 GB RAM**.

---

## Non-Negotiable Core Principle: Zero Hardcoded Knowledge

BlazeAI v5 contains **zero** hardcoded questions, answers, intent maps, keyword-to-response dictionaries, or fake pre-generated response databases.
Every single response is dynamically reasoned, tokenized, and generated on-the-fly by an open-weights instruct language model running on your local CPU.

- If the user asks *"What is Python?"*, the answer is **not** stored anywhere in the source code.
- If the user asks an unprecedented, novel question, BlazeAI synthesizes the answer through live autoregressive token generation.

### Key Technical Optimizations
1. **Streaming Generation**: Words and tokens stream directly into your console as they are generated by the model using `TextIteratorStreamer`.
2. **Key-Value (KV) Caching**: Enabled for efficient autoregressive decoding without redundant re-computations of past attention keys and values.
3. **Hardware CPU Optimization**: Tailored for Intel Alder Lake (i3-1215U) architecture using `torch.set_num_threads` and `bfloat16` precision to keep RAM footprint low (< 1 GB for 0.5B model).
4. **Context Trimming**: Automatically maintains conversation context while ensuring prompt length never overflows model limits.
5. **Real Performance Metrics**: Measures real model load time, time-to-first-token (TTFT), tokens/sec, and resident memory (RSS). Never fabricates benchmark statistics.

## Quick Start

### 1. Requirements
- Python 3.10+ (tested on Python 3.14)
- CPU: Intel Core i3 / i5 / i7 or AMD Ryzen
- RAM: 8 GB recommended

### 2. Launching BlazeAI Web UI (Recommended)
You can launch the modern web interface with a single click or command:

**Option A: Double-click launcher**
- Double-click `run_web.bat` in the `BlazeAI v5` folder.

**Option B: Terminal command**
```bash
python server.py
```
Then open your browser to **[http://127.0.0.1:8000](http://127.0.0.1:8000)**.

### 3. Launching Terminal CLI
If you prefer the purely terminal-based interface:
```bash
python main.py
```

On startup, BlazeAI loads the model weights once into RAM. Once loaded, the model stays resident throughout your session.

## Interactive Application Commands

Commands control the session and runtime parameters. None of them provide artificial AI answers:

| Command | Description |
|---|---|
| `/help` | Display command help and usage instructions |
| `/clear` | Clear active conversation history |
| `/model` | View specifications of the currently loaded model |
| `/model <name>` | Switch active model (e.g. `/model deepseek-ai/DeepSeek-R1-Distill-Qwen-1.5B`) |
| `/stats` | View comprehensive session metrics, speeds, and RAM usage |
| `/settings` | View current generation parameters (temperature, top_p, etc.) |
| `/settings <param> <val>` | Dynamically update generation setting (e.g. `/settings temperature 0.5`) |
| `/save [filename]` | Save active conversation transcript to `data/<filename>.json` |
| `/load <filename>` | Restore a previous conversation transcript |
| `/exit` | Exit BlazeAI |

## Hardware Profile & Benchmark Notes

Tested on **Intel Core i3-1215U (6 cores / 8 threads) with 8 GB RAM**:
- **Default Model**: `Qwen/Qwen2.5-0.5B-Instruct`
  - Memory Footprint: ~900 MB RAM
  - Load Time: ~1.8 – 2.5 seconds
  - Generation Speed: ~8 – 14 tokens/second on CPU
  - First-Token Latency: ~100 – 250 ms
- **Reasoning Model**: `deepseek-ai/DeepSeek-R1-Distill-Qwen-1.5B`
  - Memory Footprint: ~3.2 GB RAM
  - Load Time: ~8.8 seconds
  - Supported via `/model deepseek-ai/DeepSeek-R1-Distill-Qwen-1.5B`
